# NextPDA (Public Edition)

Современный веб-клиент для удобного чтения новостей, статей и материалов форума 4PDA.

## Возможности открытой версии
- ⚡ **Быстрая лента новостей:** живая синхронизация с материалами и статьями 4PDA.
- 📱 **Адаптивный дизайн:** продуманный современный интерфейс для мобильных устройств, планшетов и ПК.
- 🌙 **Темная тема:** оптимизированная контрастность и типографика.
- 🔍 **Удобный поиск:** быстрый доступ к публикациям и темам.

## Быстрый запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск базового прокси-сервера (порт 3001)
```bash
npm run server
```

### 3. Запуск веб-клиента в режиме разработки (порт 3000)
```bash
npm run dev
```

Или одновременный запуск сервера и клиента одной командой:
```bash
npm run dev:all
```

## Структура проекта
- `src/` — Пользовательский интерфейс NextPDA.
- `server/index.js` — Базовый открытый CORS-прокси для получения новостной ленты и открытых материалов.
- `public/` — Статические ресурсы и манифест.
